## Модуль: PaymentService

### Цель
Обработка платежей: создание, подтверждение, возврат.

### Контекст
- Часть backend API для интернет-магазина
- Интегрируется с Stripe API
- Использует PostgreSQL для хранения транзакций
- Работает в Docker-контейнере

### Метод: createPayment(data)

**Входные данные:**
```typescript
interface CreatePaymentInput {
  userId: string;           // UUID пользователя
  amount: number;           // сумма в копейках (центах)
  currency: 'RUB' | 'USD';  // валюта
  description?: string;     // описание (опционально)
}
```

**Возвращает:**
```typescript
interface Payment {
  id: string;
  status: 'pending' | 'completed' | 'failed';
  amount: number;
  currency: string;
  createdAt: Date;
  stripePaymentIntentId: string;
}
```

**Исключения:**
- InvalidAmountError — сумма <= 0 или не целое число
- UserNotFoundError — пользователь не найден
- PaymentGatewayError — ошибка Stripe API

### Правила создания платежа
1. Проверить, что пользователь существует и активен
2. Проверить, что сумма > 0 и является целым числом
3. Создать PaymentIntent в Stripe
4. Сохранить платёж в БД со статусом 'pending'
5. Отправить событие 'payment.created' в очередь
6. Вернуть созданный платёж

### Обработка ошибок Stripe
- Если Stripe вернул ошибку — НЕ создавать запись в БД
- Логировать ошибку с полным контекстом
- Пробросить PaymentGatewayError наверх

### Идемпотентность
- Использовать idempotencyKey для защиты от дублей
- Если платёж с таким ключом уже существует — вернуть его

### Edge cases
| Ситуация | Поведение |
|----------|-----------|
| amount = 0 | InvalidAmountError |
| amount = -100 | InvalidAmountError |
| amount = 1.5 | InvalidAmountError (не целое) |
| amount = 1 | Принимается (минимум 1 копейка) |
| currency = 'EUR' | InvalidCurrencyError |
| userId не существует | UserNotFoundError |
| Stripe timeout | PaymentGatewayError с retry |
| Повторный запрос с тем же idempotencyKey | Вернуть существующий платёж |
| description = 10000 символов | Обрезать до 500 символов |



5. Ограничения и требования

### Требования

**Производительность:**
- Создание платежа < 2 секунд (включая Stripe)
- Поддержка 100 платежей/секунду

**Безопасность:**
- Никогда не логировать полные данные карты
- Все суммы хранить в копейках (избежать float)
- Использовать prepared statements для SQL

**Совместимость:**
- Node.js 20+
- PostgreSQL 15+
- Stripe API v2023-10-16

**Мониторинг:**
- Метрики: payment_created_total, payment_failed_total
- Алерт если > 5% платежей failed за 5 минут
